# Test Evidence

Store screenshots or recordings that support an executed test or verified bug.

## Naming convention
- Test case: `SD-LOGIN-001_pass_YYYY-MM-DD.png`
- Bug: `SD-BUG-001_reproduction_YYYY-MM-DD.png`

## Evidence checklist
- Capture relevant page/state and enough context to understand the result.
- Remove personal information, credentials, tokens, and unrelated tabs.
- Do not fabricate or alter evidence in a way that changes the observed result.
- Reference the filename from the execution log or bug report.
