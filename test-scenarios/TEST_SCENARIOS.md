# Test Scenarios — SauceDemo

Scenarios describe high-level workflows. Detailed steps and expected outcomes are maintained in the functional test case file.

| Scenario ID | Scenario | Coverage |
|---|---|---|
| SC-01 | Verify successful and unsuccessful authentication paths. | Valid login, empty fields, invalid credentials, locked demo user |
| SC-02 | Verify inventory page content and product navigation. | Product cards, detail pages, navigation |
| SC-03 | Verify product sorting. | Available sort orders and visible ordering |
| SC-04 | Verify cart item lifecycle. | Add, remove, view, multiple products |
| SC-05 | Verify checkout validation. | Empty and populated required fields |
| SC-06 | Verify order review and completion. | Overview, totals shown by app, confirmation |
| SC-07 | Verify logout. | Menu, logout, return to login |
| SC-08 | Verify session/navigation behaviour. | Back/forward navigation and protected page behaviour |

## Scenario execution
Do not mark scenarios complete until all linked test cases have been executed and results recorded.
