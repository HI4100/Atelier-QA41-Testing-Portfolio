# Atelier QA Testing Portfolio

A hands-on software quality assurance portfolio documenting manual and API testing practice.

## Objective
Demonstrate a structured QA workflow: understand requirements, design test scenarios, execute tests, record evidence, report reproducible defects, and perform regression testing.

## Test subject
**SauceDemo** — public demo e-commerce application: https://www.saucedemo.com/

Testing covers authentication, product listing and sorting, cart operations, checkout, input validation, and (in a later phase) API testing.

## Reporting rules
Each executed test must include the date, environment, test data (without secrets), actual result, status, and evidence reference where applicable. Planned or unexecuted tests are not marked as passed.

## Scope and limitations
This is an educational portfolio exercise against a public demo application, not a production security assessment. Do not submit real personal information, payment details, or credentials. Only test within the demo site's intended functionality and applicable terms.
