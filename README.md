# Atelier QA Testing Portfolio

A hands-on software quality assurance portfolio documenting manual and API testing practice.

## Objective
Demonstrate a structured QA workflow: understand requirements, design test scenarios, execute tests, record evidence, report reproducible defects, and perform regression testing.

## Test subject
**SauceDemo** — public demo e-commerce application: https://www.saucedemo.com/

## Repository structure
- `test-plan/TEST_PLAN.md` — scope, approach, entry/exit criteria
- `test-cases/functional-test-cases.md` — 15 functional test cases
- `test-execution/TEST_EXECUTION_LOG.md` — actual execution records
- `bug-reports/BUG_REPORT_TEMPLATE.md` — reproducible defect template
- `test-scenarios/TEST_SCENARIOS.md` — high-level workflows
- `api-testing/API_TESTING_PLAN.md` — API testing approach
- `evidence/README.md` — evidence rules
